# Section crops

Numbered "Know Your Mixer" crops, generated by `python3 tools/make_section_crops.py` from the
official manual figures in `../manual-figures/`. Source figure, manual page, crop box and
enlargement for each file: see `../manual-figures/SOURCES.md`. Callout colour: red #D62839
badges with white ring and white number; letters (A, B, …) mark controls inside a pop-up
dialog so they are not confused with the main-window numbers.

To swap in real Windows captures later: drop the captures into `../manual-figures/` (or a new
folder), update the file names / crop boxes / callout coordinates in the script, re-run it,
then re-run `tools/build_pdf.sh`.
