# Section crops

Numbered "Know Your Mixer" crops, generated by `python3 tools/make_section_crops.py`
(run `python3 tools/stitch_window.py` first). Callout colour: red #D62839 badges with white
ring and white number; letters (A, B, ...) mark controls inside a pop-up dialog so they are
not confused with the main-window numbers. Every crop is enlarged with Lanczos resampling
only (adds size for print, not detail).
